## ✨ Key Features

- ⏱️ **Real-Time WPM Tracking**: Dynamically updates your Words Per Minute as you type.
- 🎯 **Accuracy Indicator**: Real-time feedback on your accuracy percentage.
- 🎨 **Visual Highlight System**:
  - 🟢 **Green**: Correctly typed characters
  - 🔴 **Red**: Incorrectly typed characters
  - 🔵 **Blue Indicator**: Active cursor position
- 📱 **Fully Responsive**: Sleek dark-mode aesthetic built for both desktop and mobile screens.
- 🔄 **Quick Restart**: Swap passages instantly and restart the 60-second timer with a single click.
