# Typing Speed Tester

A clean, modern, lightweight web application designed to measure typing speed and accuracy in real time. Built with plain HTML, CSS, and vanilla JavaScript.

## Features

- **Real-Time Speed Calculation**: Live calculation of Words Per Minute (WPM) using standard character-based formulas.
- **Accuracy Tracking**: Measures accuracy percentage based on total characters typed versus correctly matched characters.
- **Visual Feedback**: Dynamic text styling highlights correct, incorrect, and current characters as you type.
- **Responsive Layout**: Designed with modern CSS variables, dark mode styling, and responsive layout for all screen sizes.
- **Restart Functionality**: Simple one-click reset to pick a new sample passage and reset the timer.
